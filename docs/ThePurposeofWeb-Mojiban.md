# The Purposes of Web-Mojiban

# **web文字盤を作ったのはなぜか**

1990年代はじめの日本国内にはコミュニケーション支援のツールとして、伝の心、レッツチャットなどの製品とそれらの支給する画期的な制度がありました。ところがこれらを必要とする人たちの手伝いをしていると、以下のような問題があることがわかってきました。

#### 問題点

1. 費用がかかる
   伝の心は50万円と高価でしたので支給制度が作られました。
    しかし限りがある予算では高価な品は思うように進みませんでした。  
2. 時間がかかる
   制度を利用すると支給まで時間がかかろます。申請、判定、支給決定、支給、ここまで3ヶ月、悪くすると6ヶ月。余命あと数ヶ月の人は待ちきれません。
3. 多様なユーザに対応できない
   これらの支援機器は万人向けではありません。多分開発の際に多くの意見を盛り込んだため、多機能のパソコン経験者向けの製品になりました。このため小児や高齢者にはいくらか使いにくくなりました。
4. 次々と豊富な機種が出なかった
   続いて使いやすさを優先したパナソニックのレッツチャットが出てヒットしました。しかしこれ続く製品が思うほど進みませんでした。結果として市場も選択肢も拡大しませんでした。
5. 地方のディーラーは苦労した
   ニーズが限定的で数がさばけず、苦労の割に収益につながらず苦労する会社がありました。
6. 試用希望者は多いが導入には進みにくい
   レンタルなど試用の機会が少なく手間もかかりました。このように苦労しても試しただけでなかなか決まりません。患者さんには考えなければならないことが多すぎるのです。

これらを解決するために以下の対策を考えた

#### 対応策

1. 汎用ハードウエアと専用ソフトウエアを組み合わせコストを下げる。とかく高額になりがちな専用機は避ける。またハードウエアは個人持ちとする。
2. ソフトウエアをインターネットで公開し、無料で配信する。
   操作をシンプルにするためWebアプリにした。
   収益化に必要な集金コストは回収困難で赤字の原因になりやすい。収益見込みの小さい場合は無料にしたほうが損失が小さくなることも多い。無料にすれば開発費以外で赤字はない、消費税もない。収益なければ所得税もなくなる。関連する事務コストもない。さらにクレームも少ない。
3. 利益が期待しにくい取り組みには人や資金を極力注ぎ込まず、維持継続を優先するようにする。
4. ソフトウエアをオープンソースとする
   自由に使えるようにして関連する派生品の発展を促す
   だれでも自由に改良、改善し公開できる。

これらのことを考えながら制作したのが、Web文字盤です。

#### FAQ

**web文字盤をなぜwebアプリか**

人件費をゼロで運営するため。無料のサーバーを使えば、無料無人で24時間365日配信できる。githubpages　に感謝。
ユーザーがいる限り（多分）配信は止まらない、つまり持続可能性だから　2021年1月から連続稼働中

**web文字盤をなぜ自作か**

勉強すれば自分でできる。自分でやればお金はいらない。
自分のパソコンを使えば作業も勉強もできる。
勉強するのにお金はいらない。お金に困るのは誰も好きではない。
金の切れ目が縁の切れ目にならないように注意する。そんな福祉機器がたくさんあった。

**web文字盤をなぜgithubに公開するか**

将来何かの原因で利用が困難になったとき、どこかの誰かがなんとか復旧を試みる際の手がかりを残すため。たぶんその時私は手を貸せないだろうから。
また多様な障害を持つ人のコミュニケーションニーズは実に多様で、これらへの対応はとても一人で出来ないと考えたから。

国外から見に来る人が増えてきた。これは楽しいですね。
国ごとに言葉ごとに、コミュニケーション支援ソフトも必要になる。これから新しく作ろうとしている人の助けにもなるかもしれない。
